# Data provenance and numerical archives

## Source datasets

- **Breast Cancer Wisconsin (Diagnostic)**, UCI Machine Learning Repository:
  <https://doi.org/10.24432/C5DW2B>. Loaded through
  `sklearn.datasets.load_breast_cancer`.
- **Optical Recognition of Handwritten Digits**, UCI Machine Learning
  Repository: <https://doi.org/10.24432/C50P49>. The implementation uses the
  1,797-sample test-set subset distributed with `sklearn.datasets.load_digits`.

Synthetic inputs are generated by `synthetic_arrays` in `experiments.py`.
Generation and preprocessing parameters are documented in the root README.

## Export

The `--save-inputs` option saves numerical arrays in
`<results-dir>/inputs/`. The batch script enables this option automatically.
NPZ files can be loaded with `numpy.load(path, allow_pickle=False)`.

| File family | Arrays |
| --- | --- |
| `synthetic_*.npz` | `A` (design), `b` (labels), `x_true` (planted coefficients), `seed` |
| `real_*.npz` | `X_train`, `X_test`, `y_train`, `y_test`, `train_indices`, `test_indices`, `flipped_train_mask`, `feature_mask`, `scaler_mean`, `scaler_scale`, `rep`, `noise` |
| `solutions_synthetic_*.npz` / `solutions_<dataset>_*.npz` | Final vectors indexed by the six method names and scalar `lam` |
| `logistic_*.npz` | Logistic-reference final vector `x` and scalar `lam` |
| `profile_*_inputs.npz` | Inputs for the selected descent-profile instances |
| `profile_<dataset>_<method>.npz` | Profile-specific final vector `x` and scalar `lam` |
| `ablation_*.npz` | Variant final vector `x` and scalar `lam`; matching inputs are generated by the main synthetic/real experiments |

`train_indices` and `test_indices` index rows of the corresponding
scikit-learn dataset. `flipped_train_mask` indexes positions within the
training partition. `feature_mask` indexes the degree-two polynomial feature
expansion, including original features and excluding an intercept. Column
selection and scaler parameters are fitted on training data only.

Result CSV/JSON files and environment metadata accompany the numerical array
archives. The original dataset creators, repository identifiers, and dataset
licenses should be retained with redistributed data.
